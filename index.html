Zo werk ikHow I work

Vaste dagen bij vaste klanten

Op vaste beheerdagen ben ik bij de klant op locatie. Daar los ik tickets en storingen op en rol ik nieuwe werkplekken uit.

Controleren voordat het misgaat

Tijdens beheerdagen controleer ik de back-ups, het netwerk en de servers. Werkplekken en servers van klanten beheer ik met Datto RMM. Voor de beveiliging gebruiken we Datto AV en Datto EDR.

Alles vastleggen

Documentatie houd ik bij in IT Glue. Voor gebruikers heb ik handleidingen geschreven, bijvoorbeeld over MFA en Windows 365.

Scripts waar het kan

PowerShell gebruik ik voor scripts en voor instellingen in Microsoft 365 die niet via de beheerportal kunnen.

Fixed days with regular clients

On fixed support days I work on site at the client. I resolve tickets and incidents there and roll out new workstations.

Checking before things break

During support days I check the backups, the network and the servers. I manage client workstations and servers with Datto RMM. For endpoint security we use Datto AV and Datto EDR.

Writing things down

I keep documentation in IT Glue. For users I've written guides, for example on MFA and Windows 365.

Scripting where it helps

I use PowerShell for scripts and for Microsoft 365 settings that can't be changed through the admin portal.
